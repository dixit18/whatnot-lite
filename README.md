# Whatnot Lite — Live Auction for India

Inspired by Whatnot USA ($11.5B, Series G Aug 2026, US/UK/EU only).
whatnot.in unrelated. Meesho Live dead. No live-auction in India.

## Thinking
- Insta DM sellers need auction + escrow. No inventory, 8% take, Delhivery ship.
- Sellers self go-live from phone.

## Contradict
- Empty auction dead, fakes kill, COD RTO kills.
- Fix: 1 niche (cricket cards/sneakers, 5 colleges), prepay escrow only, 20 trusted sellers.

## MVP
- Go-live, bidding, escrow, ship label
- Stack: Next.js, Livekit WebRTC, Mongo, Razorpay escrow, Shiprocket
- AI: fake-check via photo

## Run
```
npm install
cp .env.example .env
npm run dev
```
